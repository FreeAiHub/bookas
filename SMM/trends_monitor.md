## Трендовые форматы (актуально на июнь 2026)

### Что работает в BookTok PT:

1. **Эмоциональный hook** — первые 3 секунды: "Este livro destruiu-me" / "Chorei com este final"
2. **Book stack / flat lay** — стопка книг по теме (5 livros de verão, 3 thrillers para ler agora)
3. **Citação + reação** — цитата из книги + эмоциональная реакция автора
4. **"Se gostaste de X, vais adorar Y"** — сравнительная рекомендация
5. **Unboxing de compras** — "O que comprei na Feira do Livro"
6. **Rating wrap-up** — итог месяца: что прочитал, оценки

### Жанры в топе (2026):
- Romance (Colleen Hoover-эффект продолжается)
- Thriller português (Rita da Nova, "Todas as Famílias Felizes")
- Dark academia / fantasy (Quarta Asa, Rebecca Yaros)
- Clássicos curtos (A Metamorfose, Noites Brancas — тренд на короткое)
- Autores portugueses (Saramago, Pessoa, Eça — вечная классика в новой подаче)

## Идеи постов на основе трендов

### Готово к использованию:

**Formato: "Se gostaste de X..."** _(высокое вовлечение)_
```
Se gostaste de "Quarta Asa" de Rebecca Yaros,
tens de ler [TÍTULO PORTUGUÊS].

A mesma intensidade. A mesma adrenalina.
Só que escrito em português.

Disponível em bookas.pt 👉

#QuartaAsa #BookTok #Bookas #LivrosPortugal
```

**Formato: Thriller português viral**
```
O thriller português que toda a gente está a ler:

"[TÍTULO]" de [AUTOR PORTUGUÊS]

Já tens? Já leste?
Diz-nos nos comentários 👇

#ThrillerPortuguês #BookTok #Bookas
```

**Formato: Clássico curto (tendência 2026)**
```
100 páginas. Uma vida de impacto.

"A Metamorfose" — Franz Kafka

O BookTok descobriu que os clássicos curtos
são perfeitos para a era da atenção fragmentada.

Tens na tua prateleira? 📚
👉 bookas.pt

#Clássicos #BookTok #Bookas #LivrosPortugal
```
